# 幕间 MIJIAN · AI 编剧共创空间

一个可直接运行的 AI 辅助写剧本交互原型。它把「定片长与题材 → 同时获得多个创意及分析 → 选择创意 → 生成剧本大纲及分析 → 扩写剧本、设计角色形象与音色、拆解分镜并汇总制作清单」做成了一条完整、可点击的创作路径。

> 当前版本是前端交互原型：创意、大纲、剧本、人物与制作清单均为**内置的高质量样本**，通过片长、题材、叙事倾向、创意选择动态编排，不调用真实模型 API。这样可以在没有密钥、网络或后端的情况下完整演示从创意到制作筹备的产品体验。

---

## 快速启动

### 方式一：本地服务（推荐）

双击 `start-preview.cmd`，它会启动服务并自动打开浏览器。

也可以在当前目录运行：

```powershell
python serve.py
```

或者使用标准静态服务器：

```powershell
python -m http.server 4174 --bind 127.0.0.1
```

然后打开 <http://127.0.0.1:4174>。

### 方式二：直接打开

直接双击 `index.html` 也可以使用。若浏览器对本地文件的存储或下载有限制，建议使用上面的本地服务。

## 体验流程

1. **故事设定**
   - 选择片长：60 秒内 / 1–3 分钟 / 3–5 分钟 / 5–10 分钟。
   - 选择 1–3 个题材，第一个选中的会作为主类型。
   - 选择叙事倾向：情感向 / 平衡 / 类型向。它会影响创意的排序与取舍。
   - 右侧「创作坐标」实时反映片长、题材组合、叙事重心与预计场次。

2. **创意选择**
   - 生成后会得到 4 个故事方向，每个方向包含：
     - 一句话故事（logline）与核心钩子；
     - AI 创意分析：叙事引擎、核心情绪、风险预判；
     - 情绪张力 / 视觉潜力 / 制作可行三项指标。
   - 点击卡片选择方向，底部会出现固定的确认栏；点击「生成剧本大纲」进入下一步。
   - 若某个方向和已选题材没有交集，会被标注为「类型越界」，作为故意保留的远端联想，而不是匹配错误。

3. **剧本大纲**
   - 左侧是完整的三幕结构，场次会按片长自动调整数量与时长。
   - 点击幕标题可折叠；点击场次可展开「转折 / 场景功能 / 视觉母题」。
   - 右侧 AI 分析面板有三个维度：
     - **核心情绪**：情绪曲线、峰值、情绪推进方式、视觉母题；
     - **人物分析**：外在欲望、内在需要、恐惧、秘密，以及逐人物切换；
     - **人物成长**：起点 → 转折 → 终点的纵向弧光，同时提供主题锚点与结构诊断。
   - 顶部可以导出 Markdown 大纲；确认结构后进入「剧本与制作」。

4. **剧本与制作**
   - **剧本正文**：按目标时长组织场次与对白，呈现为可阅读的 Shooting Script 纸张版式；左侧可跳转场次，60 秒版会自动压缩为 3 场、短版压缩为 4 场。
   - **角色与音色**：每个角色有形象方向（年龄、轮廓、服装、记忆点、色彩）和音色方向（音质、音高、语速、质感、参考、参数条），并可点击「试听台词」用系统语音确认气质。
   - **分镜表**：18 个镜头（60 秒版 9 个、短版 12 个），按场次筛选；每个镜头包含景别、运动、镜头、时长、画面描述、对白、声音与特效提示。
   - **制作清单**：角色 / 群演、场景、道具、素材、特效、镜头数量，以及六类部门清单（场景、道具、素材、特效、声音、动画）和制作风险。
   - 可以单独导出剧本 `.md`，或导出包含剧本、角色设定、分镜、场景与资产清单的完整制作包 `.json`。

## 原型里可以验证的细节

- **动态片长**：同一故事会按片长生成不同结构（60 秒 3 场 / 1–3 分钟 4 场 / 3–10 分钟 6 场），场次、剧本篇幅、镜头数与平均镜长都会重算。
- **按题材排序**：先看题材匹配度，再按叙事倾向排序；完全不匹配的方向会明确标注。
- **真实自动保存**：刷新页面会恢复上次的阶段、片长、题材、已选创意、当前分析标签和制作包模块（浏览器 localStorage）。
- **可分享的深链**：可以直接打开某个创意、大纲或制作包，方便评审。
- **移动端适配**：390px 与 320px 宽度下均可用，移动端大纲页提供「查看分析」快速跳转。
- **双导出**：剧本导出为 `.md`，完整制作包导出为 `.json`，包含剧本、角色形象与音色、分镜、场景、道具、素材、特效、声音与风险。

## 文件结构

```text
.
├─ index.html          # 页面骨架：顶栏、品牌、阶段导航、挂载点
├─ styles.css          # 完整视觉系统、布局、动效与响应式
├─ data.js             # 8 个故事创意 / 大纲 / 人物 / 情绪 / 诊断样本
├─ scripts-data.js     # 8 个故事的完整剧本正文（每故事 6 场）
├─ characters-data.js  # 16 位角色的形象与音色设定
├─ production-data.js  # 8 个故事的场景 / 道具 / 素材 / 特效 / 声音规格
├─ app.js              # 状态机、四阶段交互、海报/角色/分镜生成、导出
├─ serve.py            # 本地预览服务器（自动打开浏览器）
├─ start-preview.cmd   # Windows 一键本地预览
└─ README.md
```

## 内容与实现说明

- 视觉方向：深色编剧室 + 纸张/琥珀色 + 宋体标题，强调「创作发生在一个安静的房间里」，而不是常见的蓝紫渐变 AI 产品。
- 每个创意都有一张**程序化 SVG 概念海报**（深海舱窗、声纹、纸扎山水、电台城市、失物货架、便利店雨夜、片场聚光、排水沟月亮），不依赖任何外部图片。
- 角色有**程序化 SVG 形象方向**与音色参数；试听使用浏览器 `SpeechSynthesis`，只改变系统语音的音高与语速，用于演示「气质方向」，不是最终配音。
- 分镜帧同样是程序化 SVG，按景别、场次、故事视觉母题变化，不依赖图像生成服务。
- 所有剧本、角色、分镜与制作清单都按故事单独撰写；项目不包含外部模型调用。
- 接入真实模型时，建议保留当前数据结构，把 `getRankedIdeas()`、`buildOutline()`、`buildProduction()` 的返回值替换为模型 JSON；界面与交互不需要重写。

## 已知边界

- 这是交互与信息架构原型，不包含账号、后端、真实 AI 调用和多人协作。
- 角色音色试听依赖浏览器系统语音；不同系统上的实际音色会不同，参数与文案保持一致。
- 导出使用浏览器 Blob 下载；极少数受管控的浏览器环境可能拦截下载，但页面会给出状态提示。
- 深链参数中的中文若在聊天工具里被截断，建议从页面内正常进入。
